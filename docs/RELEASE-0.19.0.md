# Olympus 0.19.0

This release makes the current runtime inspectable without expanding its authority.

- GPT-6 Sol primary routing and explicit Astra deep analysis.
- Saved Communication Intelligence workflow, skill, node and event inspection,
  with version-bound historical records and corrected new-run trace semantics.
- A fixed, scoped Research / Verification agent pair with typed evidence exchange,
  one bounded clarification, persisted executions and read-only source authority.
- Command's operational Agent Catalog: Olympus separately from Research @1,
  Verification @1 and legacy/unproven Coding Delegate. Compiled definitions and
  persisted history supply the display; documentary candidates stay outside the HUD.
- Left catalog, preserved center instrument and reserved right chat expansion.
  Workflow and run links reuse Research inspection without execution controls.

Validation before packaging: production build passed; Rust library suite 339 passed
and 2 paid tests ignored; Command/catalog 35 browser checks, instrument 82 checks,
Research Verification 22 checks. Wide and narrow layouts were visually reviewed.
See COMMAND-AGENT-CATALOG.md and RESEARCH-VERIFICATION-AGENTS.md for detailed receipts.

Availability is configured readiness to attempt, not proof of provider credit or
successful live execution. No paid acceptance run or Coding pilot was performed.
The installer replaces 0.18.0; installation evidence and a database backup are kept
outside Git in the parent workspace's output/olympus-0.19.0-install directory.
